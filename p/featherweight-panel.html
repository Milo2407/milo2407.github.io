Featherweight Panel is a wall panel for Home Assistant built as one small HTML page. It skips the Home Assistant dashboard entirely, so slow wall screens show your home straight away instead of a loading spinner.

About 90 KB in total. On the wall screen it was first built for, the regular dashboard pulled in over 13 MB of card code before showing anything. Your numbers will differ, but a normal dashboard is several megabytes.

What it shows

  • Rooms: temperature and humidity, lights, blinds, speakers, windows and radiators. Tap a button to switch it, or tap the room for the full controls (radiator target and mode too).
  • Tabs that cycle: weather (now and 5 days), today's and tomorrow's calendar, and up to 4 pages of your own tiles (laundry, energy, anything with a state), including a live power breakdown bar.
  • Reminders: a full-screen bin-night card you can't miss, alert banners (car unlocked, garage open…) with a one-tap button, and a doorbell camera pop-up.
  • Light by day, dark at night (or always one of them).
  • Square, landscape and portrait screens.

What's included

  • The panel (index.html), a tiny Home Assistant connection script and an icon file
  • config.example.json: every room, entity and label is set in one file. No YAML, nothing to install in Home Assistant.
  • A demo mode with made-up data, so you can see it before you configure anything
  • A step-by-step setup guide with every setting explained
  • Personal-use licence

Requirements

  • Home Assistant 2024.1 or newer on your home network
  • A screen with a web browser from 2017 or later: Shelly Wall Display, an old Android tablet, a Fire tablet or a spare phone
  • A way to copy files into Home Assistant's config/www folder (File editor, Studio Code Server or Samba add-on)

Good to know

  • It uses Home Assistant's normal login. No token or password is stored in any file.
  • Files in Home Assistant's www folder can be read by anyone on your home network without logging in, so your entity names in config.json are visible on your network (states and controls are not).
  • Made with AI assistance: the panel grew out of one made for a real 4-inch wall screen, where its connection code runs every day, then was generalised and documented with an AI tool. This version was tested in demo mode in a desktop browser at square, landscape and portrait sizes; it hasn't been tried on every tablet model. The screenshots come from that demo mode, not a real home.
